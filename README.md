# 姫路の中古住宅専門サイト（デザイン案）／モリシタハウス

株式会社モリシタハウス向け、中古住宅探しサイトのトップページ **デザイン案** です。
`marketing-web-builder` スキルで、ヒアリング → 訴求設計 → 構成 → コピー → 実装の順に制作しました。

## ⚠ 掲載内容についての注意

- **これは制作中のデザイン案です。モリシタハウスの公式サイトではありません。**
- **掲載している物件情報・件数・費用の内訳はすべてダミーデータ**です（ページ最上部に注記バーを常設）
- お客様の声は未掲載（レイアウトのみ）。創作した声は載せていません
- 全ページ `noindex, nofollow`
- 会社情報（社名・所在地・電話番号・宅建業免許番号・建設業許可番号・一級建築士事務所登録番号）と
  スタッフ写真は、モリシタハウス公式サイト [m-house.co.jp](https://www.m-house.co.jp/) から取得した実データです

## 訴求の骨格

| | |
|---|---|
| 肩書き | 姫路の中古住宅専門サイト |
| キャッチ | **見つからないときは、探しに行きます。** |
| 主訴求① | 普通の不動産屋は「物件情報ありき」。要望と資金計画を聞いてから探す |
| 主訴求② | お願いしやすい人柄（担当3名の顔・資格・話し方が会う前から分かる） |
| 最優先CV | 来店・オンライン相談の予約（副：会員登録、最小：LINE） |
| トーン | B寄り（見出しの言い切りは強く、約束と期間は誠実に） |

構成は固定テンプレートを当てず、読者の疑問が浮かぶ順から導出しています。
最上級表現（No.1・地域一番・初）は使っていません。

## 構成

1. ファーストビュー（キャッチ／物件検索フォーム／要望相談CTA）
2. 探す担当（3名の顔を先に出す）
3. 掲載中の物件（件数カウンタ・新着6件・予算帯別）
4. **姫路市エリア地図** — 6エリアの3段階件数をひと目で。エリアをえらぶと学区別件数のモーダル
5. ホームページに出ている物件は、姫路の中古住宅の全部ではありません（探し方の対比・物件の2経路）
6. 総額（物件＋リフォーム＋諸費用の内訳3例）→ CTA①
7. 建物の状態は、一級建築士が見ます
8. 姫路で家を建ててきた会社が、中古住宅を探します（スタッフ3名・YouTube・免許） → CTA②
9. 正直に申し上げます。おおよそ半年を目安にお考えください（逆算タイムライン）
10. はじめの相談90分で、物件のご紹介はいたしません（分単位の内訳・約束4点）→ CTA③（予約フォーム）
11. 会員登録／お客様の声／FAQ／最後のCTA／フッター

## 技術

- 素のHTML＋CSS。ビルド不要・依存ゼロ・**JavaScriptなし**（エリア地図のモーダルも `:target` で動く）
- モバイルファースト（375px基準）。本文16px／行間1.9／タップ領域44px以上
  - 例外：地図上のバルーンのみ28px。同じリンクを48px以上で押せるエリア一覧カードを直下に併置している
- 予約フォームの `action` は未設定（送信先が決まっていないため）

## 公開前にやること

- ページ最上部のダミーデータ注記バーを削除する
- ダミーデータを実データに差し替える（掲載件数／新着物件／総額内訳3例／会員限定・店頭のみ件数／予算帯／**エリア地図の18個の件数と学区33校の件数**）
  - エリア地図の件数は `data-count="エリアkey:区分"`（区分は `public` / `member` / `shop`）で識別済み
- `要確認` 箇所を埋める（土日対応の可否、対応エリア、学区リスト、駐車場、仲介手数料、LINE URL など）
- スタッフ3名のメッセージ本文を本人確認する（現在は中古住宅向けに書き起こした案）
- 予約フォームの送信先を設定し、テスト送信して通知が届くことを確認する
- `noindex, nofollow` を外す
